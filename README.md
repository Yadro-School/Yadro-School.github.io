# Yadro-School.github.io

## Ворота перед выкаткой

```
node tools/gate.js                                   # файлы: скрипты, пути, картинки, значки входа, CSP
NODE_PATH=$(npm root -g) node tools/gate.js --browser # ещё и в браузере, ПК 1300 и телефон 390
node tools/gate.js --live https://yadro-ed.ru        # те же пути на живом сайте отвечают 200
```

Публиковать можно только после строки «ВОРОТА ПРОЙДЕНЫ».
